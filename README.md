# HATRED

A dungeon-builder / tower-defense game about an AI defending its server against a human who refuses to stay dead.

## Run

Open `index.html` in a modern browser. No build step or external dependencies are required.

## Core loop

1. Build the dungeon.
2. Start the invasion.
3. Stop the hero before they reach the server.
4. A defeated hero returns stronger.
5. A successful breach ends the run.
6. Survive the escalation to level 100.
7. At level 100, victory comes when the human finally gives up.

The repository is being developed as an incremental browser prototype.
